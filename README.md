# CSRP 构建物与附属模组仓库

本仓库用于**存储和分发** CSRP 的构建产物，以及社区玩家制作的附属模组。  
**本仓库不包含 CSRP 源代码。** 所有可下载文件均发布在 [Releases](../../releases) 中，由仓库维护者独立管理。

## 下载加速

如果从 Releases 下载较慢，可使用 GitHub 代理加速访问：

https://www.moretools.app/zh-CN/github-proxy

将 Release 文件链接粘贴到该页面，即可获取加速下载地址。该服务为第三方代理，请自行确认可用性与安全性。

## 安装

1. 根据文件标注的**加载器**（NeoForge / Forge / Fabric 等）和**游戏版本**准备对应环境。
2. 将主构建物 `.jar` 放入游戏的 `mods/` 目录。
3. 附属模组同样放入 `mods/`，并确认其兼容的 CSRP 版本与加载器。
4. 启动游戏。

> 加载器与游戏版本不一定相同，请以文件名或 Release 说明中的标注为准。  
> 附属模组由第三方作者制作，兼容性与问题请优先联系对应作者。

## 仓库用途与存储策略

本仓库只承担分发与索引，不存放二进制到 `main`：

- `main` 分支：文档与索引
- **Releases**：主构建物 JAR、附属模组 JAR
- 不推荐将 JAR/ZIP 等二进制文件直接提交到 `main`

## 版权与许可

本仓库不包含 CSRP 源代码，CSRP 的版权归其原作者所有。  
第三方附属模组的版权归其各自作者所有，本仓库仅作索引与分发。
